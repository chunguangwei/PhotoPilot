# AI Frames Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 双端本地AI按中英分类规则创建/维护相框，按需下载两种模型，发布GitHub并备好App Store更新。
**Architecture:** 复用现有FrameRepository的显式选择；AI规则/任务/成员归属由独立持久化服务管理，原照片/人工选择仍由原库负责。原生界面调用本地模型适配层，固定模型清单验证下载，未下载时禁止伪推理。
**Tech Stack:** Swift6/UIKit/CoreData、Kotlin/Views/Room；EmbeddingGemma2文本图像440M与更小多语言图像分类模型；原生本地推理运行时。
**Spec:** docs/superpowers/specs/2026-11-14-ai-frames-design.md

## Global Constraints

- iOS15+/AndroidAPI29+；新增功能中英完整，下载后可离线运行，不上传照片/提示词。
- 自动分类为可选且可事后修改；默认仅本次；持续模式按显式规则处理导入完成后的新照片。
- 必须保留人工添加和排除；隐私排除、删除、视频与未就绪照片不可入框。
- 模型与tokenizer一起计算体积；固定revision/size/SHA256，不把随机文件或英文单语模型当成轻量版。
- 允许实施期SDK与模型下载；未经过真实推理/完整构建验证不得发版。

## Review Focus

- 规则编辑与任务完成并发：过期任务不得覆盖新配置或删除相框。
- 人工排除：增量分类重跑不得加回，AI管理权不得覆盖人工添加。
- 模型切源续传：同revision/size/hash仍须验证Range和ETag，完整校验后原子安装。
- 中英分类一致性：实际图片和中英同义提示在两模型上均需真实推理，不用mock替代。
- 冷启动恢复/旧库升级：任务可恢复且已有个人相框、照片与播放不丢失。
