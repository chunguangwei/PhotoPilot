# AI 模型设置交互一致性

## 目标与现状

用户指出设置页只有 AI 模型管理采用独立跳转入口。当前双端的其他设置采用可折叠卡片，模型管理新增按钮破坏了同页交互的一致性。

## 实施

- [x] 双端设置新增与现有卡片一致的 AI 模型可折叠分组，默认收起，记忆展开状态。
- [x] 展开后直接显示已有模型状态、下载偏好、下载、暂停、继续及删除操作，复用既有控制与任务逻辑。
- [x] AI 创建页的模型管理和缺模型跳转打开同一设置分组，展开并定位指定模型，返回保留草稿。
- [x] 管理控件随父设置页自然滚动，支持中英文、窄屏与大字号，正确处理嵌入生命周期及展开后的高度。
- [x] 分组折叠或离开设置仅停止界面观察，下载及分类任务仍由既有持久协调器拥有。

## 验证与交付

- [x] 补回归证明原独立入口不符合设置分组行为，再验证展开、收起、模型聚焦及草稿回程。
- [x] 双端构建、静态分析及回归，核对手机中英与大字号实际布局。
- [ ] 主 Agent 更新词条、16交接与版本记录，按既有授权更新 GitHub。App Store 继续等待用户真机确认。

Android 与 iOS 由既有平台 Agent 分别实现，主 Agent 负责共享词条、整合、验证及发布。此次范围为设置交互一致性。
