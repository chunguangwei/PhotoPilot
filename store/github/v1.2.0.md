# PhotoPilot v1.2.0

## 中文

新增本地 AI 分类相框。

- 输入中英文分类描述，从所选相册或目录筛选照片，支持包含、排除及全部或任意匹配规则。
- 一次创建多个类别相框，预览匹配与待确认照片后保存。
- 根据描述与照片主题提供名称建议，可手动改名和调整选片。
- 两种按需下载模型为 EmbeddingGemma 2 标准版（387.7 MB）和多语 CLIP 轻量版（201.5 MB）。轻量包完整下载量减少约48%。
- 持续自动分类为可选项，默认关闭，之后可修改。支持暂停、恢复及规则变更，并保护人工添加和排除。
- 隐藏或删除照片时同步清理 AI 标签、缓存和自定义封面。

国内源优先 ModelScope，国际源使用 Hugging Face，另提供 hf-mirror 回退。文件版本固定并经 SHA256 校验，下载后在本机处理照片和提示词。备用镜像可能跳转海外 CDN。轻量模型每条描述最多126个内容分词。匹配得分表示相似度，请复核边界结果。

iOS 会检查可用内存，并在内存压力下停止 AI 任务。标准模型要求超过2 GB的物理内存。Android 标准模型要求64位进程。部分 Apple Silicon Android 模拟器存在上游 SME 能力误报，标准模型运行失败会被隔离并显示错误，可选择轻量模型。实体设备性能和国内运营商网络仍待实测。

App Store 更新材料和归档已单独准备，商店签名导出需要登录原 Xcode 发布账号并刷新匹配的描述文件。

## English

Create photo frames with local AI using English or Chinese category descriptions. Choose albums or folders, add include/exclude rules, preview matching and uncertain photos, and save separate frames with editable name suggestions. Automatic classification of future imports is optional, initially off, and editable later. Manual additions and exclusions are protected.

Download EmbeddingGemma 2 Standard (387.7 MB) or Multilingual CLIP Lite (201.5 MB). The complete Lite package is approximately 48% smaller. China sources prioritize ModelScope, global sources use Hugging Face, and hf-mirror provides a fallback. Files are pinned and SHA256-verified. Photos and prompts are processed on-device. Fallback mirrors may redirect overseas. Lite accepts up to 126 content tokens per description. Review proposed matches before saving.

iOS checks memory availability and stops AI work under memory pressure. The standard model requires more than 2 GB of physical RAM. Android standard-model inference requires a 64-bit process. Some Apple Silicon Android emulators falsely advertise SME support. Native standard-runtime failure is isolated and reported, and Lite is available on affected environments. Physical-device performance and China mainland carrier-network access remain to be tested.

App Store update materials and archives are prepared separately. Store-signing export requires the original publishing account to be signed into Xcode and a matching refreshed provisioning profile.

Complete application sources and build files are available at the release tag. Corresponding AMSMB2/libsmb2 sources and their file manifest are included as release attachments. [Tagged application source](https://github.com/chunguangwei/PhotoPilot/tree/v1.2.0)
