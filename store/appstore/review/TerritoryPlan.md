# 非中国大陆、非欧盟首发地区 / Territory worksheet — 2026-10-23

用户最新明确首发**非大陆、非欧盟地区**，覆盖此前全部非大陆含EU的拟定范围。只发布iPhone/iPad，应用无需账号登录。ASC App ID 6826092247。

## 当前实际保存范围

2026-10-23已在ASC设置特定地区：当前175个商店中选择147个，明确排除中国大陆和EU27。确认后重新读取供应情况表，28个排除地区均显示“未供应”，147地区“App发布时供应”。这只是待发布配置，不代表已经上架。关闭未来所有新商店自动加入，避免改变既定排除范围。

| 字段 | 当前决定 |
|---|---|
| 分发 | Public App Store；iPhone和iPad；不发布Mac/Apple Vision Pro |
| 价格 | 免费，无广告/内购/订阅；ASC定价另需保存核对 |
| 中国大陆 | 排除；香港、澳门、台湾独立商店均纳入 |
| EU27，包括法国 | 全部排除；法国声明不是本轮法国首发前置项，因为法国不首发。加密申报仍按SMB真实算法，不能改填仅OS加密 |
| 英国、瑞士、挪威、冰岛 | 保留；不是EU。其他可选非大陆/非EU地区保留，不把EU扩大成整个欧洲或EEA |
| 未来新商店 | 自动加入关闭 |
| 发布方式 | 手动发布；审核通过后另行上线，不自动发布 |

EU27：Austria, Belgium, Bulgaria, Croatia, Cyprus, Czechia, Denmark, Estonia, Finland, France, Germany, Greece, Hungary, Ireland, Italy, Latvia, Lithuania, Luxembourg, Malta, Netherlands, Poland, Portugal, Romania, Slovakia, Slovenia, Spain, Sweden。

## EU DSA 逐项稿

| 字段 / Field | 当前可填写内容 / Answer boundary |
|---|---|
| Trader status / 交易商身份 | 用户已确认PhotoPilot为个人业余项目；按真实页面完成单App适用声明，不修改账号其他App身份 |
| 判断事实 / Self-assessment facts | 用户确认当前个人业余、免费、无广告/内购/订阅。未来收费计划尚未实现；经营情况改变时重新评估，不承诺永不商业化 |
| 若非交易商 / If non-trader | 由主体确认本App实际在职业/经营范围之外，选择相应non-trader声明；Apple会向EU消费者展示相关消费者保护权利不适用的提示 |
| 若交易商且个人账号 / If trader, individual | 填真实公开地址或P.O.Box、电话、邮箱；验证邮件/电话，补姓名/地址和替代地址关联证明；不能用支持邮箱代替必填地址/电话 |
| 若交易商且组织账号 / If trader, organization | 核对D-U-N-S关联地址；补公开电话/邮箱及验证；信息须符合真实组织 |
| 所有交易商 / All traders | 按ASC要求补付款账户及EU合规声明，不能因下载免费推定无此要求 |
| App-specific status / 单App身份 | 核对账号级与PhotoPilot级身份设置一致，账号其他App的事实不能由本项目推断 |

Apple要求即便不在EU分发也申报身份；EU27可用性须以实际合规状态为准。EU27是：Austria, Belgium, Bulgaria, Croatia, Cyprus, Czechia, Denmark, Estonia, Finland, France, Germany, Greece, Hungary, Ireland, Italy, Latvia, Lithuania, Luxembourg, Malta, Netherlands, Poland, Portugal, Romania, Slovakia, Slovenia, Spain, Sweden。

## 其他地区与剩余账号步骤

- 不在EU分发不等于无需回应ASC账号级DSA提示。PhotoPilot个人业余事实已确认，若页面要求则按真实选项完成；账号还有其他App，不能用本App事实覆盖全部业务。
- 主体为个人注册、所在地已在门户只读核对，具体联系信息仅存ASC私有审核字段及本机0600记录，不写公开文档。
- 出口合规、第三方许可和其他地区适用要求仍需完成；排除EU不是全球豁免。未来扩展EU/法国前补齐对应材料。
- Mac/Apple Vision Pro开关与免费定价尚需独立保存和重载核验，供应地区保存不能替代这些项目。
